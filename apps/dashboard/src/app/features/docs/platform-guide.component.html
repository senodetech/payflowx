Platform User Guide & Operational Manual

How to Use

Step-by-step operational workflows for merchants, finance managers, and platform administrators.

1

Step 1: Onboarding & API Keys Provisioning

Every merchant organization registered in PayFlowX is provisioned with a secure API key pair.

  • Navigate to the API Keys page from the sidebar menu.
  • Click Rotate API Key Pair whenever credentials need to be refreshed or revoked.
  • Copy your Secret Key immediately; PayFlowX only stores one-way cryptographic SHA-256 hashes of secret keys in PostgreSQL.
2

Step 2: Simulating Checkout Charges & Card Processing

Test and simulate high-throughput card payments with instant ledger synchronization.

  • Navigate to Payments in the sidebar.
  • Click Create Charge in the top-right corner.
  • Enter the target charge amount (e.g. $150.00 USD) and test card number 4242 4242 4242 4242.
  • Upon submission, the payment state transitions to SUCCEEDED, and the double-entry ledger automatically credits Merchant Revenue and debits Gateway Receivables.
3

Step 3: Webhook Registration & Signature Verification

Configure real-time asynchronous HTTP event notifications for transaction states.

  • Go to Webhooks and input your server's endpoint HTTPS URL.
  • Check off the events to listen to (payment.succeeded, refund.succeeded).
  • Monitor delivery status, HTTP response status codes, and retry counts directly in the live delivery audit table.
4

Step 4: Executing Refunds & Balanced Accounting Audits

Execute partial or full customer refunds with mathematically balanced ledger entries.

  • From the Payments table, locate a succeeded transaction and click Refund.
  • Enter the refund amount and customer reason.
  • The system executes the refund transaction, debits Merchant Settled Funds, and credits Customer Refund Accounts in the double-entry ledger without balance deviation.
5

Step 5: Role-Based Access Control (RBAC) Hierarchy

PayFlowX enforces strict multi-tenant isolation and granular permission levels:

1. Platform Admin

Access to system-wide health, merchant KYC approvals, global ledger balances, and user role adjustments.

2. Merchant Owner

Full ownership over merchant organization, API key rotation, issuing charges/refunds, and webhook configurations.

3. Developer / Auditor

Read-only transaction monitoring, API integration testing, and cryptographic log inspection.
